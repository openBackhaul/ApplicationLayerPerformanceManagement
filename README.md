# ApplicationLayerPerformanceManagement

### Location
The ApplicationLayerPerformanceManagement (ALPM) is part of the TinyApplicationController.  
The TinyApplicationController is for managing the REST microservices of the application layer.  

### Description
Every application must send its performance measurements to the ApplicationLayerPerformanceManagement.  
The ALPM stores the performance data into an ElasticSearch database and makes it available in filtered and structured way.  

### Relevance
The ALPM is core element of the application layer running in the live network at Telefonica Germany.
